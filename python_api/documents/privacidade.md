# Privacidade e exclusão de dados

Na empresa fictícia, o administrador solicita a exclusão do espaço em Configurações → Privacidade → Solicitar exclusão. A equipe humana confirma a identidade antes de processar o pedido. O prazo fictício é de até 30 dias. No chat, o histórico fica no armazenamento de sessão desta aba e pode ser reaberto após recarregar. Até quatro pares recentes de mensagens podem ser enviados ao modelo como contexto. A chave da API fica somente na memória da página e não é incluída no histórico. Não envie dados pessoais, senhas ou dados financeiros.

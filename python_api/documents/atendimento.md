# Atendimento humano

A equipe fictícia atende de segunda a sexta, das 9h às 18h, no fuso America/Recife. O prazo inicial previsto é de até 1 dia útil. O contato demonstrativo é suporte@nexo.example e não recebe mensagens. O agente prepara um resumo para copiar, mas não envia e-mail nem abre chamados reais.

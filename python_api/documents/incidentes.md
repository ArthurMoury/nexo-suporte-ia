# Falhas e indisponibilidade

Se o Nexo não carregar, atualize a página, teste outra conexão e tente uma janela privativa. Se a falha persistir, prepare um atendimento com horário, navegador e descrição do erro, sem dados pessoais. Não há painel de status conectado nesta demonstração. O agente não pode confirmar incidentes em tempo real.

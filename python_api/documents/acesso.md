# Recuperação de acesso

Na tela de login, escolha Esqueci minha senha e informe o e-mail cadastrado. O link de recuperação expira em 30 minutos. Confira spam e lixo eletrônico. Se o link expirar, solicite outro. Se continuar sem receber, prepare um atendimento. Nunca compartilhe senhas ou códigos de autenticação com o agente.

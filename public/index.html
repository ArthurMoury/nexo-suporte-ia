Como o agente constrói uma resposta

O modelo interpreta a conversa e solicita ferramentas. O código Python consulta os documentos e devolve o contexto ao modelo, que redige a resposta final.

  1. 1Interface do chat

    Sua mensagem e o contexto recente da conversa.

  2. 2Orquestração em Python

    Instruções, limites e ferramentas disponíveis para o agente.

  3. 3LLM via API

    Gemini ou OpenAI interpreta o pedido e escolhe a consulta.

  4. 4Tool calling

    O modelo solicita rag_search ou read_document com argumentos.

  5. 5RAG em Python

    A função busca e ordena trechos relevantes dos documentos.

  6. 6Documentos da base

    Políticas e textos da Nexo, mantidos como arquivos Markdown.

O caminho de volta

Trechos dos documentos → resultado da ferramenta → LLM redige a resposta → chat exibe o texto e as fontes.

A recuperação atual usa busca lexical BM25 em Python. Não há embeddings nem banco vetorial nesta versão. O painel “Por trás da resposta” mostra as chamadas realmente realizadas.

Uma empresa, toda de exemplo

Nexo é uma loja fictícia de assinaturas de software. Preços, políticas, clientes e chamados foram criados para este projeto. O agente explica procedimentos e prepara resumos. Ele não acessa contas reais, envia mensagens ou executa cancelamentos e reembolsos.

Um agente com ferramentas em Python

A interface envia a conversa ao backend. O orquestrador Python consulta o LLM, executa chamadas de ferramentas e retorna seus resultados ao modelo. Gemini e OpenAI têm adaptadores de API. Não há árvore de perguntas fixas nem resposta predefinida apresentada como se fosse do modelo.

Qualidade que pode ser conferida

O repositório inclui benchmark em Python, testes de fontes, fatos, ferramentas e encaminhamentos. O GitHub executa as verificações a cada atualização. Um juiz semântico opcional complementa os testes e precisa de calibração humana.

Como funciona o histórico

As mensagens ficam no armazenamento de sessão desta aba. Você pode reabrir a conversa após atualizar a página. Até quatro pares recentes de mensagens são enviados ao modelo como contexto. Não há sincronização com uma conta. A chave da API fica apenas na memória da página e precisa ser reconectada após recarregar.

Dados e privacidade

Sua mensagem, o contexto recente e os documentos recuperados são enviados ao provedor de IA pelo backend. Chaves de API não são incluídas no histórico e não são gravadas pela aplicação em logs ou arquivos. Não envie informações pessoais ou credenciais no chat. Hospedagem e provedor têm políticas próprias de retenção.
